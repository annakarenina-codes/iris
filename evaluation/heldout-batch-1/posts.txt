# IRIS held-out batch 1: posts and expected results
#
# One "### POST" block per post. Lines starting with # are ignored. Empty blocks are skipped.
# Paste the post text exactly as shown between the <<< and >>> lines.
# Fill EXPECTED OVERALL, EXPECTED CLAIMS and REFERENCES BEFORE running IRIS (see README.md).
#
# Category:          news | filipino | quote | false_claim | opinion_satire | other
# IMAGE:             for a post whose words are in a picture: images/H07.jpg (see below).
#                    Leave blank for a text post. Never retype the words of an image here:
#                    IRIS must read them itself, and a wrong reading is a result worth having.
# EXPECTED OVERALL:  Verified | Partially Verified | Not Found | Refuted | No Checkable Claims
# EXPECTED CLAIMS:   one "- " line per checkable statement, ending with "=> <expected verdict>"
# REFERENCES:        one "- " line per article URL that supports (or, for false claims, debunks) the post
#
# Image posts: save the picture in this folder's images/ directory, as a phone screenshot
# rather than a cropped or sharpened copy, under 8 MB, .jpg .jpeg .png .webp .bmp .tif .tiff.
# If the post has BOTH a picture and a caption, put the picture in IMAGE and leave TEXT empty:
# IRIS reads one or the other, the way the extension and the phone app do.
#
# The EXAMPLE blocks below are fictional and are never run.
