IRIS Options

Configure the Chrome extension frontend for backend testing.

IRIS sends only the text you select, or the image you submit, to the verification server. It does not read pages on its own and nothing is sent until you ask for a check.

Developer settings

IRIS sends selected text to `/verify` and submitted images to `/verify-image` on this backend.

Matches IRIS_API_TOKEN on the server. Kept in this browser only, never in the repository.

History

History is stored only on this browser.
